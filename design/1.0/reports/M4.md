# Atlas 1.0 · M4 审查报告

基线 `4504697`（M3），本地 `redesign/m4-polish`。此处记录隔离验收，不是发布或日用配置安装授权。

## Plan

1. **QB-1 · 可访问性。** 两套主色及内置变体的文字、控件边界、焦点与减弱动态；在真实预览里用键盘遍历目的地、内容、会话与表单，验证焦点可以回来。
2. **QB-2 · 性能。** 测真实客户端的标签帧、缓存 Desk 和主题路由，区分输入防抖、请求和下一帧；检查多个原生会话的保留上限、节点身份与隐藏布局成本。
3. **QB-3 · 降级。** sessions、layout、Agent Teams、model selection 不可用时，核实读与导航、原位解释与不执行错误动作。说明使用了什么测试替身。
4. **使用手册与交付。** 更新 README 和使用指南，用纯合成研究的日/夜截图，分别检验源码预览和实际打包内容，最后对精确候选包做私人 DSH 验收。

## 实测与取舍

| 要求 | 审查结论与证据 |
| --- | --- |
| QB-1：键盘与语义 | 真实私有 DSH 的键盘路径从宿主侧栏开始，覆盖七个目的地、话题、真实讨论、源文件、PDF、组队表与成员。对话框双向循环焦点，Escape 归还给触发控件。参见[键盘路径及未覆盖操作](m4/keyboard.md)。不是屏幕阅读器或整站 WCAG 认证。 |
| QB-1：可辨识与减弱动态 | 两个内置主题中，测试组合最弱的次要文字 ≥4.60:1，控件边界 ≥3.18:1，焦点 ≥5.17:1。修复原本难辨的日间状态、输入外框和弱文字；减弱动态时 6 类动态标识停止、跳转不再平滑滚动。范围不含自定义色、第三方会话或论文自带的颜色；见[对比度实测](m4/contrast.md)。 |
| QB-2：切换、Desk、路由 | [基准方法与逐项范围](m4/performance.md)。40 次已保留对话切换均 <50 ms，同一回复的 DOM 对象不变；8 次缓存 Desk 均 <300 ms。7 个讨论保留 6 个正文，第 7 个释放的是最久未用的后台正文，不是删除会话。隐藏 Desk 和讨论的各 10 次布局探针均无新增 layout，对照组每次均有。 |
| QB-2：150 ms 如何计时 | **有口径差异。** DK-12 要求停笔 250 ms 后才请求。最终候选实测最后输入→建议可见 p95 **282.3 ms**（0/12 <150 ms），而请求→同一可见建议 p95 **27.1 ms**。保留输入规范，不把两段延迟混报为 27 ms，不拿本机数据承诺所有机器或网络的表现。 |
| QB-3：可选服务 | [降级证据](m4/resilience.md)。在同一个真实 DSH/Chromium 测试宿主，只对 Atlas 的临时副本逐一隐藏 sessions、layout、Agent Teams、modelCatalog、selectModel。缺 sessions 还能开本地 PDF；无 layout 可以在 Atlas 内聚焦/退出；无团队服务只能看组队表；失去模型选择时明确阻止带旧偏好的发送，不创建空会话。用户主动改用 DSH 默认后才建一个会话并收到真实 fixture 回复。不是声称把宿主的全局服务卸载后 DSH 自身仍能运行。 |
| M4.4：说明书 | [快速上手](../../../README.md) 与[完整指南](../../../docs/guide.md) 区分源码预览、成品安装和回滚，标明根目录、DSH 会话、文件变动的归属边界。只用合成研究的双主题素材；包内不再附 0.x 设计为当前权限说明。 |

## 最终候选与复现

- **审查发现已实修**：Tab / Shift+Tab 能离开文本和 TeX 编辑器；Write 的分隔条有键盘操作，实测宽度由 301 到 307 px 后可复位。在真实 Web DSH 中，Ctrl+W 属于浏览器、Ctrl+Alt+W 又被此宿主占用；面板实际提示另一组合 Ctrl+Alt+Shift+W。焦点在右侧最后一页的正文按钮上时，按下它只关 Atlas 标签，焦点回到左侧选中的 Library。Learn 不仅能打开，还能键盘换题并读到目标正文。独立复核未再发现上述阻断，不代表外部 Claude 或研究者已签字。
- **结果**：最终客户端指纹 `3dc58c7127d9`。两次完整键盘演练分别 848、858 次按键。运行 `ATLAS_M4_CONTRAST_UI=1` 下的 `npm test`：**211/211**，0 skip。实际最终 `.tgz` 使用**归档内**安装器在临时 headless/web/Desktop profile 上 **15/15**。日常阅读、M2 双会话与 Undo、旧索引迁移、跨工作区交接，以及 M3 双席团队/决策浏览器回归通过。五种受控缺服务场景和最终性能/键盘浏览器运行均无控制台、页面、HTTP 错误。运行时环境与限定条件分别见各项证据。
- **成品**：工作区 `dist/aitp-atlas-1.0.0.tgz`，46 个文件，1,816,764 字节，SHA-256 `bbacf41971d294a21c2cadb78b3fc488fa8e78d2aa4ff28d8ef33db585773717`。`node scripts/verify-package.mjs dist/aitp-atlas-1.0.0.tgz` 核对归档与所审源码的逐文件字节、入口、文档链接、资源和许可。`node test/dsh-e2e.mjs dist/aitp-atlas-1.0.0.tgz` 验证离线安装与重启。测试使用本地合成 Skills，不代表已测从 Git 首次在线获取上游 Skills。未推送、未发布，未在日用 profile 安装。
